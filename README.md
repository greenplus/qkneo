# [素数大富豪NEO](https://greenplus.github.io/qkneo/)

登録した素数・合成数とアシスト候補を使い、素数を暗記していなくても戦略から遊び始められる素数大富豪クライアントです。

- 初級: 7枚、偶数半減、ペナルティ1枚
- 上級: 11枚、通常デッキ、通常ペナルティ
- 登録表、アシスト、HNPチャレンジ
- Gold／Silver CPUとの1人練習
- 対戦募集、グローバルチャット、切断復帰

ゲームサーバーは `greenplus/primeqk_online_server`、共通UIの作業用正本は親ワークスペースの `client-common/` と `neo-client-prototype/` にあります。
